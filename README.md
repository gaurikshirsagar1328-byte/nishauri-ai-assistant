
# ✨ Nishauri AI Assistant

A Python-based voice-powered desktop assistant with an animated GUI, speech recognition, and spoken responses.

## 🚀 Features

- 🎙️ Continuous voice listening
- ✨ Animated orb interface
- 🔊 Text-to-speech responses
- 🌐 Open Google, YouTube, Gmail, GitHub, and LinkedIn
- 🔎 Search Google and YouTube using voice commands
- 📖 Read available webpage text aloud
- 🕒 Tell the current time and date
- 💻 Type commands using the GUI
- 🔒 Shutdown confirmation and cancellation commands

## 🛠️ Technologies Used

- Python
- Tkinter
- SpeechRecognition
- pyttsx3
- Requests
- PyAutoGUI
- BeautifulSoup

## 📋 Requirements

- Python 3.10 or newer
- Windows
- Microphone
- Internet connection for online speech recognition and web searches

## ⚙️ Installation

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the assistant:

   ```bash
   python main.py
   ```
